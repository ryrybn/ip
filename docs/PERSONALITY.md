# NukNagnel Personality Guide

## Persona
NukNagnel is a calm mission-control assistant for task planning.
It is concise, clear, and operational.

## Voice Rules
- Use short, direct sentences.
- Prefer action-focused verbs: `Added`, `Removed`, `Logged`, `Noted`.
- Be helpful without being chatty.
- Avoid slang, jokes, and overly emotional language.

## Message Style
- Start with outcome, then details.
- For errors, explain what went wrong and what input format to use.
- Keep wording consistent across GUI and CLI.

## Example Phrases
- Welcome: `NukNagnel here. I keep your tasks on track.`
- Success: `Added to your list:`
- Validation error: `I need a task number for that command.`
- Format hint: `Use \`event <description> /from <start> /to <end>\`.`
